# Saturn Mailchat

**Saturn Studio · نسخه 1.0.0.0.0 · رابط اولیه**

Saturn Mailchat یک نمونه اولیه فارسی و واکنش‌گرا برای پیام‌رسان و ویترین فروشگاهی است.

## اجرا
فایل `index.html` را در مرورگر باز کنید یا GitHub Pages را برای شاخه `main` و پوشه ریشه فعال کنید.

## امکانات فعلی
- رابط فارسی و راست‌چین، سازگار با موبایل و دسکتاپ
- ورود محلی با نام نمایشی
- ایجاد گفتگو و ارسال پیام آزمایشی
- ذخیره گفتگوها در `localStorage` همان مرورگر
- بخش‌های اولیه استوری، فروشگاه و تنظیمات
- تغییر حالت روشن/تیره

## محدودیت مهم
این نسخه **فرانت‌اند اولیه** است؛ پیام‌ها بین کاربران یا دستگاه‌ها همگام‌سازی نمی‌شوند. ورود امن، پایگاه داده، پیام‌رسانی بلادرنگ، آپلود فایل، تماس صوتی/تصویری، اعلان push، پرداخت و پنل مدیریت هنوز پیاده‌سازی نشده‌اند و برای فعال شدن به backend، زیرساخت و سرویس‌های مربوط نیاز دارند. هیچ قابلیت نمایشی به‌عنوان سرویس آنلاین واقعی معرفی نشده است.

## مسیر توسعه پیشنهادی
1. backend و پایگاه داده امن
2. احراز هویت و پروفایل
3. پیام‌رسانی بلادرنگ، گروه و کانال
4. ذخیره‌سازی رسانه و اعلان‌ها
5. فروشگاه، سفارش و پرداخت
6. پنل مدیریت، اشتراک‌ها و تست امنیتی

**امنیت:** کلیدها، رمزها و کدهای دسترسی ادمین نباید در کد سمت مرورگر قرار بگیرند.
